CanineConnect 🐾

A Canine Marketplace & Community Application

CanineConnect is a web application concept designed to connect prospective dog owners with people offering dogs for sale. The project combines my background in veterinary medicine with my interest in software engineering and digital solutions for animal-related services.

🎯 Project Overview

The application explores how technology can simplify the process of discovering and connecting with canine sellers while providing a structured platform for managing canine listings and user interactions.

🛠️ Technologies

* HTML
* CSS
* JavaScript

🧑🏽‍⚕️ Why I Built It

As a veterinarian, I am interested in applying technology to animal health, animal services and veterinary-related problems.

CanineConnect was an opportunity to explore software development while working on a problem directly connected to my professional background.
